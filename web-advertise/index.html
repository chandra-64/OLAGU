TCP 3-Way Handshake:
1. SYN: Client sends a SYN segment with an initial sequence number to initiate the connection.
2. SYN-ACK: Server acknowledges with an ACK and responds with its own SYN segment.
3. ACK: Client sends an ACK segment back. The full-duplex connection is established and data transmission begins.
